Расширение для Chrome, которое возвращает выдаче Авито читаемость. Гасит объявления, которые
вы уже открывали, ставит штамп на перекупов и показывает, сколько мест на странице занял один
продавец.

Ни сборки, ни зависимостей, ни сетевых запросов. Два разрешения.

---

## Зачем

Ищете популярный товар — и почти каждая карточка принадлежит не частнику, а профессиональному
продавцу. Замер на живой выдаче «iPhone 16»:

> **47 витрин из 50. Медиана отзывов у продавца — 868. Продавцов с 20 отзывами и меньше —
> ни одного.**

Родной фильтр «Частные» у Авито есть, но он делит продавцов по форме регистрации, а не по
поведению. Под «Частными» на той же выдаче живьём попадаются ООО, сеть по продаже телефонов
и скупка с 1 470 отзывами.

Поэтому расширение делает две вещи, которых площадка не делает: ставит её же родной фильтр
**прямо в адрес выдачи**, чтобы страницы приходили плотными, а поверх применяет свой критерий.

## Что делает

| | |
|---|---|
| **Гасит уже открытое** | Состояние хранится по объявлению, поэтому две вкладки не затирают друг друга. Передумали — рядом кнопка «вернуть». |
| **Ставит штамп на профи** | МАГАЗИН, АГЕНТСТВО, АВТОСАЛОН, РАБОТОДАТЕЛЬ — слово зависит от раздела. Тем, у кого витрины нет, но торгует потоком, достаётся ПЕРЕКУП. |
| **Видно, кто занял страницу** | «ещё 7 объявлений этого продавца» — прямо на карточке. |
| **Один тумблер** | Всё остальное работает само, настраивать нечего. |

Критерий «профи» составной: витрина по адресу `/brands/`, **или** 20+ отзывов, **или** 3+ места
в одной выдаче. Пороги лежат одним объектом в `src/config.js`.

## Что получается

Живые страницы, сколько карточек осталось после фильтрации:

| Раздел | Живых карточек |
|---|---|
| Телефоны | 13 из 49 (было 1) |
| Мебель | 26 из 50 |
| Детская одежда | 27 из 82 |
| Аренда | 43 из 58 |

## Установка

**Из исходников, любой браузер на Chromium:**

1. Скачайте репозиторий или возьмите архив в разделе [Releases](../../releases).
2. Откройте `chrome://extensions/`
3. Включите **Режим разработчика**
4. Нажмите **Загрузить распакованное расширение** и выберите папку.

Работает только на Авито. Настраивать ничего не нужно.

## Как это устроено

То, что оказалось неочевидным, и что показали замеры.

**Пустого экрана не бывает.**
Если под фильтр попадают вообще все карточки на странице, не прячем ни одной — остаются только
штампы. Это не теория: на выдаче автосалонов сработало на 50 карточках из 50. Прежняя версия
гасила всё и оставляла белый экран.

**Замирание на 0,8 секунды, найденное прибором, а не на глаз.**
По три прогона на сторону, самая длинная задача:

| | Самая длинная задача |
|---|---|
| Без расширения | 109–125 мс |
| Версия 1.1.1 | 732 / 933 / 732 мс |
| Версия 1.1.2 | 214 / 196 / 211 мс |

Причина: проход по карточкам чередовал записи в DOM с чтениями вычисленного стиля, а каждое
такое чтение заставляет браузер пересчитать раскладку заново. На полусотне карточек это
складывалось в почти секундное замирание. Что доказало диагноз: с включённым тумблером
рисуется 24 штампа вместо 47, и задержка падала до 192 мс — цена росла вместе с числом штампов.

**Одно состояние — один ключ со знаком.**
Два отдельных ключа давали гонку между вкладками и залипшие карточки. Знак несёт смысл:
плюс — просмотрено, минус — пользователь вернул руками.

**Перерисовка решается подписью, а не флагом «обработана».**
Флаг оставлял 2 карточки из 50 без штампа при обычном переходе по сайту, потому что Авито
перерисовывает карточки под вами.

**Клиентское гашение не чинит пагинацию.**
Страницы у Авито серверные, поэтому прятать карточки локально — значит всё равно листать десять
пустых страниц. Лечится установкой родного параметра фильтра в адрес, с правилом, когда его
ставить НЕ надо: площадка сообщает «показать всех» удалением параметра, а не его значением.

## Тесты

28 регрессионных тестов в пяти наборах — разбор, отрисовка, хранилище, окно расширения,
производительность. Гоняются на DOM-фикстурах обычным Node, без фреймворков:

```bash
node tests/run-fixture-regression.cjs
# или
bash tests/run-fixture-regression.sh
```

Проверяют ровно те поломки, которые случались: пустой экран, гонку хранилища между вкладками,
ленивую подгрузку карточек, штамп поверх родной метки Авито и счётчик поверх колонки фильтров.

## Приватность

- **Ни одного сетевого запроса.** Проверено: ни `fetch`, ни `XMLHttpRequest`, ни маячков.
- **Два разрешения:** `storage` и `activeTab`, host-разрешений нет.
- **Один сайт:** контент-скрипт срабатывает на одном домене.
- Всё, что расширение помнит, лежит в локальном хранилище браузера и никуда не уходит.

## Стек
